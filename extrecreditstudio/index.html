How to Play

Press Start Game to begin. The button switches to Roll Dice and Player 1 takes the first turn.

Each roll uses all six dice. If the total is even, that total gets added to the current player's score. If the total is odd, no points are added and the turn moves to the next player.

The first player to reach 100 points wins. Each goal readout shows how many points that player still needs to win.
